## Portfolio post

**What I'm working on**

I work in benefits and compensation analytics, mostly in Power BI. I'm good at the last mile: the model, the DAX, the report someone opens on Monday. What I want to get better at is everything upstream: where the data comes from, how it's tested, and how it gets from a raw extract to a number a Total Rewards manager can trust.

So I'm building that whole path myself, in public, for a fictional company called Northwind Mutual. Over the next year it grows into a synthetic HR, payroll and benefits data generator, SQL, dbt models with tests, a Power BI layer and a small AWS pipeline. All the data is fake and generated from code. Nothing comes from any real employer.

**What I learned today**

Day 1 was Git and GitHub. Git keeps a history of a project, and the workflow maps neatly onto accounting:

- A **commit** is like a posted journal entry: a saved change with a description.
- A **branch** is your working copy. Committing there doesn't touch `main`. (I got this wrong on today's quiz, which is why I'm writing it down.)
- A **pull request** is sending your work for review before it posts. Writing `Closes #1` links the PR to the request that started it, so anyone can trace a change back to the business ask and the review. That's the same idea as tying an entry to its support.

**What was hard**

Not the concepts, the mechanics. I typed commands into the wrong window, saved a file inside the wrong folder, and committed a message that was literally the placeholder text. I also hit Windows' "running scripts is disabled" error the first time I tried to activate a Python virtual environment. Each error message told me exactly what was wrong once I slowed down and read it.

**What I built**

My first Python script prints one fake employee. The seed makes it print the same person every run, which matters later when tests need repeatable data:

```python
"""Print one fake Northwind Mutual employee."""
from faker import Faker

Faker.seed(42)
fake = Faker()

employee_id = 100001
name = fake.first_name() + " " + fake.last_name()
hire_date = fake.date_between(start_date='-10y', end_date='today')
job = "Compensation Analyst"
salary = 120000

print(f"Name: {name}")
print(f"Salary: ${salary:,}")
```
